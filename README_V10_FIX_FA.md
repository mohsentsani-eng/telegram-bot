نسخه V10 اصلاح‌شده ترنم همدلی

این نسخه بر پایه V9 ساخته شده و ظاهر پنل را دست‌نخورده نگه می‌دارد.

اصلاحات:
- انتخاب رشته نهم از حالت پیام ثابت خارج و به یک فرم چندمرحله‌ای واقعی تبدیل شد.
- دکمه بازگشت برای مراحل ثبت‌نام و ارزیابی بهتر شده است.
- فیلتر ارزیابی تحصیلی همچنان دقیق است: پایه، رشته، درس، فصل، مبحث، سطح.
- هیچ fallback به درس یا مبحث دیگر وجود ندارد.
- سؤال‌های تکراری از نظر محتوایی نباید دوباره وارد شوند.
- این نسخه دیتابیس موجود را حذف یا reset نمی‌کند.

نکته: برای شروع کاملاً تمیز، قبل از اولین اجرا می‌توانید data/taranom.db را حذف کنید؛ برنامه دیتابیس جدید می‌سازد. اگر دیتابیس فعلی را نگه می‌دارید، دانش‌آموزان و نتایج حفظ می‌شوند.
