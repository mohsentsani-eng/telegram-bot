# سیستم یکپارچه آموزشی ترنم همدلی

این نسخه یک هسته یکپارچه واقعی برای بات + CRM + پنل مدیریت است.

## امکانات
- ثبت‌نام اجباری دانش‌آموز قبل از ورود به خدمات
- پرونده یکتا بر اساس Telegram ID
- ثبت منبع جذب با deep-link `/start source_name`
- گیت عضویت کانال آموزشی (اختیاری)
- بانک سؤال مستقل از کد
- ورود دستی و CSV سوال
- آزمون تحصیلی: پایه/رشته/درس/فصل/مبحث/سطح
- ثبت پاسخ، نمره و mastery هر مبحث
- ارزیابی روان‌شناختی ـ تحصیلی و ذخیره در پرونده
- ارزیابی مهارت‌های یادگیری
- ثبت برنامه اولیه، کوچینگ و درخواست‌های مشاوره
- فرم اطلاعات انتخاب رشته کنکور
- شروع پرونده انتخاب رشته نهم
- CRM مدیر و مشاهده پرونده دانش‌آموز
- ردیابی منبع جذب: Instagram / Telegram / Website / School / Referral

## راه‌اندازی
1. `.env.example` را به `.env` تغییر نام دهید.
2. BOT_TOKEN، ADMIN_PASSWORD و ADMIN_SECRET را تنظیم کنید.
3. اختیاری: برای اجبار عضویت کانال:
   - `REQUIRED_CHANNEL_ID=@YourChannel`
   - `REQUIRED_CHANNEL_URL=https://t.me/YourChannel`
   - بات باید در کانال ادمین باشد.
4. نصب:
   `pip install -r requirements.txt`
5. اجرا:
   `python -m app.main`
6. پنل مدیر:
   `http://127.0.0.1:8000/admin/login`

## افزودن سؤال
- پنل → «افزودن سؤال»
- یا پنل → «ورود CSV»
- قالب نمونه: `data/questions_template.csv`

## نکته منابع
سؤالات مؤسسات خصوصی را فقط در صورت داشتن مجوز/حق استفاده وارد کنید.
برای سایر موارد از سؤالات رسمی مجاز یا سؤالات تألیفی مستقل استفاده کنید.

## امنیت و دسترسی
- دانش‌آموز فقط «پرونده من» را می‌بیند.
- پنل مدیر با نام کاربری/رمز و Session محافظت می‌شود.
- در حالت فعلی پنل روی 127.0.0.1 فقط روی همان کامپیوتر قابل دسترسی است.
- برای دسترسی از بیرون باید روی سرور با HTTPS و احراز هویت قوی deploy شود.

## حفظ اطلاعات
- این نسخه هیچ فایل دیتابیس موجود را همراه خود ندارد.
- در اولین اجرا فقط اگر جدول questions خالی باشد، seed_questions.csv وارد می‌شود.
- اطلاعات دانش‌آموزان موجود حذف یا جایگزین نمی‌شود.
- قبل از هر تغییر بزرگ، از data/taranom.db نسخه پشتیبان بگیرید.


## نسخه Proton VPN
این نسخه عمداً هیچ Proxy داخل aiogram تنظیم نمی‌کند. اگر Proton VPN روشن باشد، اتصال بات از مسیر VPN سیستم انجام می‌شود.

اجرای پروژه:
```powershell
python -m pip install -r requirements.txt
python -m app.main
```
پنل مدیریت: http://127.0.0.1:8000/admin

## بانک سؤال توسعه‌یافته

نسخه توسعه‌یافته شامل بانک سؤال تألیفی پوشش‌دهنده پایه‌های چهارم تا دوازدهم است. برای متوسطه دوم، رشته‌های تجربی، ریاضی و انسانی نیز پوشش داده شده‌اند.

- بانک توسعه‌یافته: `data/expanded_questions.csv`
- ورود بانک به دیتابیس به‌صورت incremental و بدون حذف اطلاعات قبلی انجام می‌شود.
- اجرای مجدد برنامه باعث ایجاد سؤال تکراری نمی‌شود.
- سؤال‌های `konkur_style` سؤال‌های تألیفی هم‌سبک کنکور هستند و متن سؤال‌های کنکور را عیناً بازنشر نمی‌کنند.


## رفتار امن بانک سؤال در این نسخه
- بانک سؤال به‌صورت پیش‌فرض **خودکار Seed نمی‌شود**؛ منبع اصلی ورود سؤال، پنل CSV است.
- برای استفاده عمدی از بانک همراه پروژه، `AUTO_SEED_QUESTIONS=1` را در `.env` قرار دهید.
- اجرای مجدد برنامه سؤال‌ها را تکثیر نمی‌کند.
- قبل از حذف یا پاک‌سازی داده‌ها از `tools/backup_db.py` استفاده کنید.
- در آزمون، سؤال‌های تکراری legacy نیز در زمان انتخاب فیلتر حذف می‌شوند تا کاربر دو بار یک سؤال نبیند.
