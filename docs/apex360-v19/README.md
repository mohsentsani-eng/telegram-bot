# مقایسهٔ تصویری Apex360

تصاویر از اجرای کد نسخه‌های ۱۸ و ۱۹ در آزمون رابط Flutter، با اندازهٔ یکسان ۳۹۰ × ۸۴۴ و داده‌های ساختگی مشترک ثبت شده‌اند. در هر مقایسه نسخهٔ ۱۸ سمت چپ و نسخهٔ ۱۹ سمت راست است. پنج صفحهٔ پس از ورود به فضای شخصی آفلاین تعلق دارند. در نسخهٔ ۱۸، قلم نصب‌شدهٔ محیط آزمون نقش قلم جایگزین سیستم را دارد.
